### colophon

I'm Wally, a robotics developer at SUSTech and a former member of the algorithm team at SUSTech Robocon ARES. My work has ranged from robot perception and control to building a NixOS environment for training and deployment. I'm currently exploring algorithms for legged robots.

I like systems that are clear to understand, comfortable to use, and practical to maintain.

### selected work

- [**Folio**](https://github.com/WallyHao/folio-nixos-config) — a modular NixOS desktop and development environment, shaped around daily use.
- [**AlignGrasp**](https://github.com/WallyHao/align-grasp) — alignment perception and autonomous grasping for a ROS 2 robot.
- [**Robo Mind**](https://github.com/WallyHao/robo-mind) — embodied robot control with a body/brain architecture.
- [**Tag Atlas**](https://github.com/WallyHao/tag-atlas) — multi-AprilTag spatial localization and pose fusion.
- [**Chirp Comm**](https://github.com/WallyHao/chirp-comm) — short text communication over sound.
